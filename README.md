# Portfólio · Beatriz de Castro Estradé

Site de portfólio com projetos de marketing, campanhas, design, redes sociais, e-mail marketing, sites e planejamentos.

## Estrutura

- `index.html`: a página completa (HTML, CSS e JavaScript num arquivo só).
- `img/`: imagens dos projetos.
- `files/`: vídeos e o currículo em PDF.

## Como abrir

Abra o `index.html` no navegador. Para publicar como site, ative o GitHub Pages em **Settings → Pages**, escolhendo a branch `main` e a pasta raiz.

## Observações

- Dados sensíveis de clientes (preços, telefones, métricas internas e fotos de terceiros) foram borrados ou removidos antes da publicação.
- A versão principal do portfólio também está publicada como artefato no Claude. O botão "Organizar miniaturas" só funciona lá.
